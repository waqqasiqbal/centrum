# Support

AI Interfaces is an experimental research prototype maintained on a best-effort basis.

## Where to ask

- Use a GitHub discussion or a clearly scoped issue for usage questions when those
  features are enabled.
- Use the bug-report form for reproducible defects.
- Use the feature-request form for proposed capabilities or design changes.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose them publicly.

Before opening a request, search existing issues and include the project version,
Node.js version, operating system, reproduction steps, expected behavior, and sanitized
logs. Remove API keys, tenant data, environment files, and generated demo credentials.

The maintainers do not currently provide response-time guarantees, production support,
or private implementation consulting through this repository.
