# Governance

AI Interfaces currently uses a maintainer-led governance model.

## Maintainer

Waqqas Iqbal (`@waqqasiqbal`) is the current project maintainer and final decision maker
for releases, security boundaries, roadmap scope, and repository administration.

## Decision process

Small fixes and documentation changes may proceed through a focused pull request.
Changes to public contracts, capability authority, mutation policy, tenant isolation,
or security boundaries should begin with an issue or ADR and include relevant tests.

Decisions favor user safety, deterministic authority, backward compatibility, clear
operational ownership, and maintainability. When reasonable alternatives exist, the
maintainer should record the tradeoff in the pull request or an ADR.

## Becoming a maintainer

Maintainer access may be offered to contributors who demonstrate sustained, high-quality
contributions, sound security judgment, constructive review, and reliable stewardship.
The current maintainer appoints additional maintainers and records the change here.
